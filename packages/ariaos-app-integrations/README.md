# `ariaos-app-integrations` Package

Configurations, patches, and Arch packaging hooks that enable native API control across pre-installed apps out of the box:
- **Brave / Firefox**: Native Messaging host manifests & optional local CDP profile flags
- **LibreOffice**: UNO local socket launcher/configuration
- **OBS Studio**: Pre-enabled `obs-websocket` local loopback configuration
- **Audacity**: `mod-script-pipe` module enabled by default
- **AUR Recipes**: Build recipes (`brave-bin`, `vscodium-bin`, `yay`) for the local `archiso` pacman repo
