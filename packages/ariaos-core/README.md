# `ariaos-core` Package

Arch Linux `PKGBUILD` for installing the core AI operating system layer:
- `/usr/bin/aria-daemon` (compiled from `core/daemon/`)
- `/usr/lib/ariaos/sdk/` (from `core/sdk/python/`)
- `/usr/lib/ariaos/connectors/` (from `connectors/`)
- `/usr/lib/systemd/system/aria-daemon.service` & Polkit rules
